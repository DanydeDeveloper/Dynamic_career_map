# Dynamic Career Map

MVP веб-приложения для Private.Education: динамическая профориентационная карта школьника 5-7 класса.

Система помогает педагогу вести профиль ученика, фиксировать диагностику, планировать мероприятия, собирать фидбэк и подтверждать предложения изменений перед обновлением траектории.

## Стек

- Next.js + TypeScript
- Prisma + SQLite
- React server components

## Локальный запуск

```bash
npm install
copy .env.example .env
npm run prisma:generate
npm run db:init
npm run db:seed
npm run dev
```

## Vercel

Для первого демо-деплоя используется локальная SQLite-база, которая создается на этапе сборки:

```bash
npm run vercel-build
```

Это подходит для MVP-просмотра интерфейса. Для реального сохранения данных в продакшене нужно заменить SQLite на hosted PostgreSQL, например Supabase, Neon или Vercel Postgres.

## Принципы MVP

- Без авторизации: первый запуск работает как единый кабинет педагога.
- Данные хранятся локально в SQLite.
- AI-слой не изменяет профиль напрямую: он формирует предложения, педагог подтверждает решения.
- Автоматический парсинг сайтов не входит в первый этап.
